# Pi 桌面终端 UI 设计规约

本规约定义 Lure 当前 GPUI 纯 Rust 界面与交互的最终状态。

## 产品与界面边界

- Lure 是面向单个用户的 Pi 桌面终端，不包含账户、组织、团队、订阅或协作能力。
- 主工作区直接呈现 Pi 原生 TUI；模型、认证、会话、命令、工具、skills 和 extensions 均由 Pi 提供。
- Lure 只负责窗口、工作目录、PTY 生命周期、终端字节流、ANSI/VT 字符网格、尺寸同步和故障恢复。
- ANSI/VT 仅用于终端绘制，不解析或重建 Agent、工具、会话或 TUI 组件语义。
- 不在终端外重复实现 Pi 功能，不设置常驻侧栏、右栏、文件树或独立对话流。

## 页面布局

```text
┌──────────── GPUI 自定义标题栏（48px）────────────┐
│ 窗口控制 · Lure / 工作目录 · 终端操作             │
├───────────────────────────────────────────────────┤
│                                                   │
│             Pi TUI / 原生字符网格                 │
│                                                   │
└───────────────────────────────────────────────────┘
```

- 应用采用单一终端工作区，不使用 WebView。
- 自定义标题栏高 48px：macOS 左侧使用 AppKit 原生关闭、最小化到 Dock 和缩放交通灯（可被系统窗口菜单及窗口管理工具识别），其他平台左侧提供调用系统窗口操作的关闭、最小化和缩放控制；中部显示工作目录，右侧提供选择目录、重新启动和停止操作。macOS 标题栏双击遵循系统的窗口缩放或最小化偏好，拖动使用原生窗口移动接口。应用不创建独立后台托盘：最小化保留当前 Pi 进程与终端状态，关闭窗口则回收进程。
- 工作目录过长时截断显示；目录选择使用系统原生文件夹选择器。
- 终端填满标题栏之外的空间，四周保留 8px 内边距。
- 最小窗口尺寸为 720 × 480；窗口变化后按 8 × 16px 字符单元重新计算列数和行数，并同步 PTY。
- 根容器禁止滚动，Pi 的 alternate screen 与光标状态由终端状态机维护。
- 状态面板覆盖终端区域，但不遮挡标题栏和窗口控制。

## 终端行为

- PTY 输出以原始字节进入 Alacritty 终端内核，由其维护 ANSI/VT、字符网格、光标、历史与终端模式；GPUI 按可见字符单元绘制，不进行 Markdown 化或消息卡片转换。终端内核对控制序列查询的回复经 PTY 发回 Pi。
- 展示层支持 ANSI 16 色、256 色、真彩色、粗体、斜体、下划线、反色、光标和 alternate screen。
- 终端获得焦点后，按终端模式将文字、控制键、方向键、导航键和 F1–F12 编码后写入 PTY；Pi 启用扩展键盘协议时 Shift+Enter 发送可区分的修饰键序列，未启用时遵守传统终端协议。
- 终端必须注册 GPUI `InputHandler`：中文、日文等输入法的预编辑文本显示在 Pi 光标处，候选窗口锚定到光标位置，确认后的 UTF-8 文本一次性写入 PTY；预编辑阶段不得把拼音字母提前发送给 Pi。
- Pi 启用鼠标报告模式时，鼠标点击与释放按终端协议转发 Pi；未启用时左键拖动选择终端字符，显示半透明选区，松开后自动复制到系统剪贴板。跨行复制保留换行并移除每行未选择的尾部填充空格；单击不覆盖剪贴板。不得根据 Pi TUI 输出文字建立点击热点。
- `Command/Ctrl + V` 从系统剪贴板粘贴到 PTY；其余 Pi TUI 快捷键不由 Lure 解释。
- 启动成功后终端保持焦点；目录选择结束后可继续输入。
- 选择新目录时先停止当前 Pi，再在新目录启动；取消选择不影响当前会话。
- 鼠标滚轮或触控板在普通终端屏幕中浏览最多 10,000 行历史输出；向上滚动时保持当前位置，新输出不得强制跳回底部，用户再次输入时返回实时输出。浏览本地历史时显示独立的可点击「Back to bottom」按钮，点击返回实时输出；历史区域不绘制实时光标，实时光标尊重终端内核的可见性模式。Pi TUI 使用 alternate screen 时不得尝试滚动本地 scrollback：若 Pi 已启用鼠标协议则发送对应滚轮序列，否则回退为上下方向键，使 TUI 自己处理内容滚动。
- 停止或退出后保留已有终端内容，并允许在相同目录重新启动。
- generation 标识隔离旧会话输出，避免重启后串流。
- 关闭窗口时回收 Pi 子进程、PTY reader 和消息任务。

## 状态与恢复

- 启动中显示低干扰状态，不伪造 Pi 输出。
- 启动失败时展示具体错误和重试操作。
- Pi 退出后展示退出代码和重新启动操作，不清空终端内容。
- 输出或输入转发失败时保留已显示内容，并提供重试路径。
- 不自动无限重启 Pi。

## 视觉与可用性

- 窗口外框使用 16px 圆角和细边框。窗口保持系统原生可缩放、可移动、可最小化的顶层窗口属性，允许系统窗口平铺与第三方窗口管理工具操作；macOS 应用包与 Dock 使用仓库内 `assets/logo.svg` 生成的 Lure 图标。
- 应用统一使用浅色 Gruvbox 主题：主背景 `#FBF1C7`，标题栏 `#EBDBB2`，主要前景 `#3C3836`，次要前景 `#7C6F64`。
- 终端使用完整 Gruvbox Light ANSI 色板，并支持 ANSI 256 色与 RGB 真彩色。
- 终端字号 13px，字符网格与显式行高均为 8 × 16px；拉丁字母与 Nerd 图标使用 `JetBrainsMono Nerd Font Mono`，中文依次回退到 `Sarasa Mono SC`、`PingFang SC`、`Hiragino Sans GB`，Emoji 回退到 `Apple Color Emoji`。同一样式的普通字符合并为文本 run；双列宽字符独立锚定到对应网格列塑形，避免中文回退字体的自然字宽累积造成光标偏移。先绘制单元格背景、再在 GPUI canvas 的网格坐标绘制塑形文本；禁止用固定宽度文本 div 相互覆盖，以完整展示历史输出中的中英文、Nerd 图标和 `p`、`y`、`g` 等下降部。
- 状态面板使用 Gruvbox 浅色卡片和低对比边框，不使用大面积高饱和色。
- 所有操作均有稳定的控件位置和足够点击区域；状态和错误同时使用文字表达。
- 窗口级操作只位于标题栏，不占用 Pi TUI 的常规按键语义。
