# Pi 桌面终端 UI 设计规约

本规约定义 Lure 当前 GPUI 纯 Rust 界面与交互的最终状态。

## 产品与界面边界

- Lure 是面向单个用户的 Pi 桌面终端，不包含账户、组织、团队、订阅或协作能力。
- 主工作区直接呈现 Pi 原生 TUI；模型、认证、会话、命令、工具、skills 和 extensions 均由 Pi 提供。
- Lure 只负责窗口、项目目录列表、PTY 生命周期、终端字节流、ANSI/VT 字符网格、尺寸同步和故障恢复。项目列表由 Lure 独占读写 `$HOME/.pi/projects.yaml`；Lure 不创建 `.pi` 目录，也不读取或修改其中其他内容。
- ANSI/VT 仅用于终端绘制，不解析或重建 Agent、工具、会话或 TUI 组件语义。
- 不在终端外重复实现 Pi 功能；首页和终端页共用可收起的项目导航侧栏；不设置右栏、文件树或独立对话流。

## 页面布局

```text
首页
┌────────────── GPUI 自定义标题栏（48px）──────────────────┐
│ 窗口控制 · [切换侧栏] · Lure · 版本 · [主题] [+ 新建项目] │
├───────────────┬───────────────────────────────────────────┤
│ 工作台导航    │ 项目工作区 · 运行中数量   全部/运行中/未打开 │
│ 项目 · 数量    │ 简介                                      │
│ 本地项目目录  │ [项目卡片] [项目卡片] [项目卡片]          │
└───────────────┴───────────────────────────────────────────┘

终端页
┌────────────── GPUI 自定义标题栏（48px）─────────────┐
│ 窗口控制 · [切换侧栏] · 项目 / 活动项目 · 主题 · 新建 │
├───────────────┬──────────────────────────────────────┤
│ 项目 · 返回首页 │       活动项目的 Pi TUI 字符网格 [X] │
│ 本地项目目录  │                                      │
│ 活动项 · 状态  │                                      │
└───────────────┴──────────────────────────────────────┘
```

- 应用包含首页与终端页，不使用 WebView。首页从 `$HOME/.pi/projects.yaml` 读取项目并以卡片展示；首页和终端页共用可收起的项目列表侧栏；每个打开的项目对应一个在该目录运行的 Pi 交互进程，侧栏负责切换会话。
- 首页采用随手动主题切换的双栏布局：220px 侧栏展示「项目」与全部已保存的本地项目目录，右侧展示卡片网格。标题栏的侧栏图标与 `Command/Ctrl + B` 在首页和终端页切换侧栏的展开/隐藏；收起后工作区占用释放的宽度。侧栏项目列表可独立滚动，侧栏的「项目」入口及终端标题栏的「项目」按钮返回首页，不停止正在运行的进程。侧栏的项目行可打开或切换会话，项目行仅展示名称和状态点，不提供关闭或停止按钮，活动行有选中态；关闭当前终端并停止 Pi 由终端区域右上角的 X 图标按钮控制。首页不提供项目搜索框或 `Command/Ctrl + K` 搜索快捷键；筛选按钮仅按本地 Pi 子进程是否运行分类。运行中计数只统计本地正在运行的项目会话；不从终端输出推断任务进度、模型或推理状态。
- 首页与终端页支持 `Command/Ctrl + E` 呼出项目切换弹框（创建项目名称表单打开时不触发），列表顺序与侧栏一致，不受首页筛选影响；默认选中当前终端项目，否则选中第一项。弹框展示项目名称和路径，使用当前主题背景、边框及选中色。`Command/Ctrl + J` 或下方向键向下选择，`Command/Ctrl + K` 或上方向键向上选择，到列表首尾停止；选中项自动滚入可见区域。回车或点击项目复用侧栏的打开/切换行为，关闭弹框并将焦点交给目标终端，不重启已有会话。`Esc`、再次按 `Command/Ctrl + E` 或点击遮罩关闭弹框，不改变活动项目。无项目时显示新建提示，回车不启动进程。弹框打开期间键盘与输入法文字不转发给 Pi，列表滚轮不影响终端；导航快捷键仅在弹框内生效。
- 首页卡片宽 310px、高 190px，包含项目名称、运行状态、单行省略路径和打开终端提示；点击侧栏目录或卡片打开相同的项目终端。标题栏右侧创建按钮始终使用原生目录选择器；从终端页创建后直接打开新项目会话，从首页创建后留在首页。品牌、侧栏开关、创建、项目矩阵、目录与卡片图标使用 `assets/home/` 中的 SVG 资源，经 GPUI 渲染；不使用字体字符作为图标。
- 自定义标题栏高 48px：macOS 左侧使用 AppKit 原生交通灯，其他平台提供系统窗口控制；首页显示 Lure、版本、主题切换及创建项目，终端页显示活动项目名称及返回首页入口，右侧仅提供主题切换和新建项目，不提供关闭、停止与重启按钮。右侧两个操作统一居中、间距 8px，距窗口右侧 16px；主题按钮为 32 × 32px 次要图标按钮，创建按钮高 32px、左右内边距各 12px，图标 14px 与文字间距 6px；二者均使用 8px 圆角及主题对应悬停色，创建按钮使用主题主按钮底色和高对比文字。macOS 标题栏双击和拖动遵循系统行为，侧栏开关及其他按钮不触发窗口拖动。
- 首页项目卡片内的项目名称与路径上下排列、垂直居中，均限制在卡片内边距范围内；过长时单行省略，不得溢出卡片。侧栏项目名称及终端标题过长时截断显示。侧栏项目状态使用固定 6 × 6px 的实心圆点，垂直居中且不可被压缩；运行中使用鲜明绿色（浅色 `#16A34A`、深色 `#4ADE80`），未打开使用中性灰色（浅色 `#A3A3A3`、深色 `#525252`）；状态色独立于文字辅助色，深浅主题尺寸一致，不使用字体圆点字符。创建项目使用系统原生文件夹选择器，以目录最后一层为默认名称，名称可编辑或留空；空名称展示时回退为目录名。
- 最小化保留所有项目会话的 Pi 进程和终端状态；侧栏切换不回收会话，终端区域右上角的关闭按钮停止活动项目的 Pi 并回收该会话，返回首页；关闭窗口回收全部进程。
- 终端填满标题栏及展开侧栏之外的空间，四周保留 8px 内边距。
- 终端区域右上角悬浮关闭按钮，距顶部和右侧各 8px，点击区域 28 × 28px，内部为 14px SVG X 图标，无可见文字；使用当前主题的圆角细边框、表面色与悬停色，无障碍名称为「关闭当前终端并返回首页」。按钮位于状态面板上方，启动中、运行中、退出和故障时均可点击；点击停止当前项目的 Pi、回收当前会话及图片纹理并返回首页，不自动切换到其他终端，不影响后台项目。再次打开该项目时启动新的 Pi 进程。按钮拦截鼠标按下、释放与滚轮事件，不向 Pi 转发，也不触发终端选区；「Back to bottom」按钮右侧偏移 44px，避开关闭按钮。
- 首次启动窗口默认 1200 × 800 逻辑像素，在主屏幕可用工作区内居中；宽高分别限制为工作区的 90%，最小尺寸 720 × 480 优先于该比例。工作区小于最小尺寸时，启动布局以可见工作区为上限。普通窗口移动和缩放后将布局原子保存至 `$HOME/.config/lure/window.yaml`，不读写 Pi 配置；后续启动恢复尺寸和位置，不受首次启动的 90% 限制，但会收缩和移动至当前可见工作区内。显示器断开时回退主屏幕；配置缺失或损坏时使用默认布局。最大化与全屏不覆盖普通窗口布局，不自动恢复最大化或全屏。
- 最小窗口尺寸为 720 × 480；窗口变化或侧栏展开/收起后扣除窗口外框、可见侧栏宽度与终端内边距，按 8 × 16px 字符单元重新计算列数和行数，并将字符网格的像素宽高一并同步到 PTY winsize，保证 Pi 的图片尺寸换算与可见网格一致。
- 根容器禁止滚动，Pi 的 alternate screen 与光标状态由终端状态机维护。
- 状态面板按活动项目会话的生命周期覆盖终端区域，但不遮挡标题栏与侧栏，也不影响其他项目在后台运行。

## 终端行为

- PTY 输出以原始字节进入 rio-vt 终端内核，由其维护 ANSI/VT、字符网格、光标、历史、终端模式与 Kitty Graphics 图片状态；GPUI 按可见字符单元与图片 placement 绘制，不进行 Markdown 化或消息卡片转换。终端内核对控制序列查询的回复（包括 Kitty Graphics 的 `ESC_G...OK` 响应）经 PTY 发回 Pi。
- 展示层支持 ANSI 16 色、256 色、真彩色、粗体、斜体、下划线、反色、光标和 alternate screen。

## 终端内联图片

- Pi 通过 Kitty Graphics 协议（`ESC_G` APC）发送的内联图片由 rio-vt 解析为解码后的 RGBA 像素与 placement；Lure 不解析图片控制序列本身，也不读取 Pi 会话文件或重建任何业务语义。
- 每张图片按 image id 缓存为一张 GPU 纹理；重复传输同一 id 只替换该纹理，不产生额外副本；删除命令（如 `a=d,d=I`）释放对应纹理。
- 图片按 placement 的网格列行、单元格跨度、子单元格偏移、源裁剪矩形和 z-index 绘制，并被裁剪在终端内容区域内，不越过终端边界或侧栏。Kitty placement 的绝对行号与文字可见行必须使用同一历史原点：计算视口顶部时包含已从历史缓冲区逐出的行数，避免图片在历史清理后与预留位置错行。
- 绘制顺序为：单元格背景、负 z-index 图片、文字、非负 z-index 图片、选区、光标。图片随字符网格滚动，placement 滚出可视区后不绘制；浏览本地 scrollback 时历史图片随对应行出现。
- 主屏幕与 alternate screen 各自维护独立的图片集合，切换屏幕时各自恢复。
- 每个项目会话独立持有图片纹理，图片替换、删除或回收时从 GPU atlas 移除对应旧纹理；后台项目会话的图片事件也及时回收。关闭项目会话时回收全部纹理；进程退出后保留已有终端图文，直到关闭或替换该会话。多个项目会话使用相同 image id 互不影响。
- 资源上限：单张图片解码后不超过 16 MiB 像素数据（超出直接丢弃）；每个项目会话图片纹理合计不超过 64 MiB；全应用所有项目会话合计不超过 256 MiB。超过上限时按最久未使用顺序回收纹理，被回收的图片不再绘制但不影响终端文字输出。
- 图片解码或绘制失败时仅缺失该图片，终端文字与交互不受影响；日志不记录图片 Base64 内容。
- 终端获得焦点后，按终端模式将文字、控制键、方向键、导航键和 F1–F12 编码后写入 PTY；Pi 启用扩展键盘协议时 Shift+Enter 发送可区分的修饰键序列，未启用时遵守传统终端协议。
- 终端必须注册 GPUI `InputHandler`：中文、日文等输入法的预编辑文本显示在 Pi 光标处，候选窗口锚定到光标位置，确认后的 UTF-8 文本一次性写入 PTY；预编辑阶段不得把拼音字母提前发送给 Pi。预编辑区域先以当前主题终端背景覆盖底层文字、反色单元格及选区，再绘制完整的带下划线组合文本；组合输入期间不绘制终端光标，避免遮挡首字母，确认或取消后恢复终端原始网格与光标。
- Pi 启用鼠标报告模式时，鼠标点击与释放按终端协议转发 Pi；Pi 请求拖动或全部移动报告（1002/1003）时，从终端开始的左键拖动持续转发位置报告，跨网格才发送，原地停留不重复发送；拖出终端后仍转发拖动与释放，位置限制在网格内。仅启用点击报告（1000）时不发送拖动报告。未启用时左键拖动选择终端字符，按住移动时实时更新半透明选区，无需松开；拖出终端区域仍继续更新，选区终点限制在终端网格内，松开后自动复制到系统剪贴板。窗口失焦、切换会话或离开终端页时结束拖选，不自动复制；已保留的选区不随无关鼠标移动改变。跨行复制保留换行并移除每行未选择的尾部填充空格；单击不覆盖剪贴板。不得根据 Pi TUI 输出文字重建按钮、卡片或面板等可点击 TUI 组件；链接命中只按下一节的路径与网址形态规则产生。
- 终端链接由两条通道共同产出，且**只做形态与位置判断，不重建 Pi 的 Agent、工具、会话或 TUI 组件语义**：
  1. **显式超链接**：rio-vt 把 `ESC ] 8` 的目标地址绑定到单元格，Lure 读取该元数据并合并成链接区间。链接文本中的宽字符占位单元格同样属于该链接。
  2. **路径与网址识别**：对可见网格文本做形态识别，覆盖 Pi 以纯文本输出的文件路径。Pi 的 TUI 只对 Markdown 链接与图片回退发送 `ESC ] 8`，工具卡片内的路径是纯文本，因此该通道是提供与 iTerm2 同等能力所必需的。
- 两条通道重叠时显式超链接优先；识别结果只用于「哪段文字可以点」，不参与任何内容渲染或语义推断。
- 路径识别的匹配形态为：以 `/` 开头的绝对路径、以 `~/` 开头的家目录路径、含 `/` 且末段带扩展名或至少三段的相对路径、带扩展名的裸文件名，以及显式 `http`／`https`／`mailto`／`ftp` 网址。以下形态一律不识别：纯数字与版本号（`1.5.2`）、计量值（`14s`、`56 tokens`）、MIME 类型（`image/png`）、裸单词、裸域名（`example.dev`）、比式表达式（`1/2`）、非白名单 scheme（`javascript:`、`vscode:`）、界面框架文字（分隔线、状态行、`click to show more` 等提示）。
- 识别以带网格坐标的字符流为对象：宽字符按其实际列宽计入，软换行的行尾不插入分隔符，因此跨行折断的长路径仍能拼成一段并在每一行分别可点；非软换行的行尾插入分隔符，避免相邻两行被误拼。`file.rs:42`、`file.rs:42:7` 结尾的行号在打开前剥离。
- 相对路径以当前项目目录为基准解析；`~/` 展开为用户主目录。`file:` 目标经百分号解码后必须为绝对路径，`#L42` 等编辑器行号片段在打开前去除。无法解码或无法解析的目标直接拒绝。
- 链接区间在终端输出、滚动、resize、侧栏展开／收起与会话切换后重算；同一帧内复用缓存，不逐帧重复扫描全视口。
- 按住系统修饰键（macOS 为 `Command`，其他平台为 GPUI 的 `platform` 修饰键，即 `Win`/`Super`）并悬停链接时，指针变为手型并给整段链接绘制低透明度主题强调色底纹；松开修饰键立即恢复。修饰键事件沿「焦点节点 → 根」派发，必须注册在承载焦点的节点上，保证不移动鼠标也能刷新光标形状。终端页之外、标题栏、侧栏、终端内边距与网格外区域不产生手型光标或链接高亮。输入法预编辑期间不响应链接悬停与点击。
- 修饰键 + 左键点击链接优先于 Pi 鼠标报告与拖选：打开目标后不启动选区、不向 Pi 转发点击（同一次手势的松开一并吞掉，避免发出孤立释放）、不改变焦点外状态；不按修饰键时的点击行为与未实现该能力前完全一致。仅允许 `http`、`https`、`mailto` 与 `file` 四类目标，其他 scheme 一律忽略并给出非阻塞提示，不交给系统默认协议处理器。
- 打开动作交由系统默认应用，失败不打断终端输出，提示以不遮挡终端内容的浮层呈现，可点击关闭。
- Lure 通过 `PI_HYPERLINKS` 显式向 Pi 声明已支持 OSC 8 超链接渲染，并在 spawn Pi 时清除从宿主终端继承的探测变量（如 `KITTY_WINDOW_ID`、`ITERM_SESSION_ID`、`GHOSTTY_RESOURCES_DIR`），保证从不同终端或从文件管理器启动 Lure 时 Pi 的输出形态一致。图片协议与真彩色仍按既有探测流程处理，不在此声明范围内。
- `Command/Ctrl + V` 在运行中的终端从系统剪贴板粘贴到 PTY，不自动提交；遵循终端 bracketed paste 模式，启用时过滤内容中的 ESC，防止提前结束粘贴。其余 Pi TUI 快捷键不由 Lure 解释。
- GPUI 返回图片条目时，优先将图片以原始格式保存到系统临时目录，使用 `lure-clipboard-` 前缀的随机独占文件（Unix 权限 0600），将完整绝对路径作为文本粘贴；不传输图片二进制、不解析 Pi 业务语义。无图片条目时保留普通文本/文件路径粘贴。macOS 底层读取优先级为文件 URL、文本、图片，因此同时包含文本与图片的系统剪贴板可能按文本粘贴。
- 图片文件不随粘贴结束、会话关闭或应用退出删除，交由系统临时目录策略管理，不保证长期会话恢复后仍存在。落盘失败显示原生错误提示，不发送无效路径，不停止 Pi。项目名称表单仍只接受文本粘贴。
- 创建或打开项目后终端保持焦点；从侧栏切换项目后焦点移动到目标会话；创建项目的目录选择结束后焦点回到名称表单。
- 打开或新建项目时在该项目目录启动新的 Pi 进程；同一 canonical 路径只允许一个项目会话，重复打开切换到已有会话。侧栏切换或返回首页不停止、不重启后台进程。
- 鼠标滚轮或触控板在普通终端屏幕中浏览最多 10,000 行历史输出；向上滚动时保持当前位置，新输出不得强制跳回底部，用户再次输入时返回实时输出。浏览本地历史时显示独立的可点击「Back to bottom」按钮，点击返回实时输出；历史区域不绘制实时光标，实时光标尊重终端内核的可见性模式。Pi TUI 使用 alternate screen 时不得尝试滚动本地 scrollback：若 Pi 已启用鼠标协议则发送对应滚轮序列，否则回退为上下方向键，使 TUI 自己处理内容滚动。
- Pi 自行退出后保留已有终端内容，并允许通过状态面板在相同目录重新启动；主动「关闭终端」则回收当前终端内容并返回首页。
- 会话 id 与 generation 二级隔离消息：项目会话关闭后丢弃迟到消息，同一会话重启后隔离旧进程输出。
- 关闭窗口时回收全部项目会话的 Pi 子进程、PTY reader 和消息任务。

## 状态与恢复

- 启动中显示低干扰状态，不伪造 Pi 输出。
- 启动失败时展示具体错误和重试操作。
- Pi 退出后展示退出代码和重新启动操作，不清空终端内容。
- 输出或输入转发失败时保留已显示内容，并提供重试路径。
- 不自动无限重启 Pi。

## 视觉与可用性

- 窗口外框使用 16px 圆角和细边框。窗口保持系统原生可缩放、可移动、可最小化的顶层窗口属性，允许系统窗口平铺与第三方窗口管理工具操作；macOS 应用包与 Dock 使用仓库内 `assets/logo.svg` 生成的 Lure 图标。
- 标题栏在首页与终端页均提供 32 × 32px 的纯图标主题切换按钮：当前为浅色时显示靛蓝月亮，点击切换至深色；当前为深色时显示浅黄太阳，点击切换至浅色。图标为 `assets/home/` 中的 SVG，不显示文字，按钮通过无障碍标签说明目标主题。点击立即切换整个窗口；只有深色、浅色两个选项，不跟随系统。启动默认浅色，选择在当前应用生命周期内保留。切换不改变项目、会话、终端文字、滚动位置或光标，不重启 Pi，不读写 Pi 配置。
- 浅色主题参考瓷白工作室设计：主画布与终端默认背景 `#F7F8FA`，侧栏 `#F0F2F5`，卡片与输入框 `#FFFFFF`，分隔线 `#E2E5EC`，主文字 `#0F172A`，次要文字 `#475569`，辅助文字 `#64748B`，强调色与创建按钮 `#4F46E5`，选中背景 `#E0E7FF`，运行状态 `#047857`，错误色 `#B91C1C`。弹窗、故障面板与筛选状态同步切换；不引入设计稿中的数字员工、任务或检查器功能。
- 深色主题的终端页使用 Dracula 配色：主背景 `#282A36`，标题栏 `#21222C`，主要前景 `#F8F8F2`，次要前景 `#A6ABCB`，边框 `#44475A`，强调色 `#BD93F9`，错误色 `#FF5555`。首页使用近黑底色 `#090B0D`、侧栏及标题栏 `#0E1014`、卡片 `#101419`、细边框 `#242A30`、青绿色 `#2AD7A5` 状态点及低对比灰蓝辅助文字。界面不展示数字员工、任务队列、模型信息等 Pi 业务状态。
- 深色终端使用 Dracula ANSI 16 色板，浅色使用适配浅底的高对比 ANSI 16 色板。默认前景、背景及反色随主题切换；ANSI 256 色中的扩展颜色与 RGB 真彩色保持 Pi 指定值，不根据输出语义改色。终端按当前主题回答 Pi 对默认前景、背景和 ANSI 色板的颜色查询，使 Pi 自行绘制用户输入区域与回复的区别；桌面端不按消息角色重新着色。
- 终端字号 13px，字符网格与显式行高均为 8 × 16px；拉丁字母与 Nerd 图标使用 `JetBrainsMono Nerd Font Mono`，中文依次回退到 `Sarasa Mono SC`、`PingFang SC`、`Hiragino Sans GB`，Emoji 回退到 `Apple Color Emoji`。同一样式的 ASCII 字符合并为文本 run，按实际塑形宽度补偿字符间距以贴合 8px 网格；非 ASCII 字符与双列宽字符独立锚定到对应网格列塑形，避免字体自然字宽累积造成光标偏移。先绘制单元格背景、再在 GPUI canvas 的网格坐标绘制塑形文本；禁止用固定宽度文本 div 相互覆盖，以完整展示历史输出中的中英文、Nerd 图标和 `p`、`y`、`g` 等下降部。
- 启动、退出与错误状态面板使用当前主题标题栏色作为卡片背景，外层使用同色半透明遮罩，搭配主题边框和前景文字；不使用大面积高饱和色。
- 所有操作均有稳定的控件位置和足够点击区域；状态和错误同时使用文字表达。
- 窗口级操作只位于标题栏，不占用 Pi TUI 的常规按键语义。
