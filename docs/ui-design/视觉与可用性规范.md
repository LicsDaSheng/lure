# 视觉与可用性规范

## 视觉语言

- 窗口外框保持 16px 圆角、细边框和透明原生窗口背景。
- 标题栏和终端使用中性深色，减少 TUI 与应用外壳之间的视觉断层。
- 终端背景默认 `#191919`，前景默认 `#ECECEC`，光标与选择色保持足够对比度。
- 终端字体栈优先 `SFMono-Regular`、`Menlo`、`Monaco`、`Consolas` 和通用 monospace。
- 状态覆盖层采用低对比卡片，不遮盖标题栏，不使用大面积高饱和色。

## 可用性与无障碍

- 所有窗口和会话按钮都有可访问名称、键盘焦点态和不低于 36 × 36px 的点击区域。
- 状态和错误不能只用颜色表达，必须包含文字。
- 终端容器提供描述其用途的标签，xterm.js textarea 保持可聚焦。
- 系统启用“减少动态效果”时停止加载旋转动画。
- 文本和背景满足可读对比度；终端字号不得低于 12px。
