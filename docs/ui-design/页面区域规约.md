# 页面区域规约

## 应用标题栏

- 桌面窗口不使用系统默认装饰；标题栏由桌面端统一绘制，高 40px，并固定在工作区顶部。
- 左侧品牌区显示简洁 Logo 与产品名，中间区域用于拖动窗口；双击拖动区沿用系统的最大化/还原行为。
- 右侧依次提供最小化、最大化/还原和关闭按钮。按钮必须有可访问名称、清晰焦点态和悬浮反馈；关闭使用红色悬浮反馈，其余保持低对比中性色。
- 标题栏只承载窗口级操作，不展示任务状态、RPC 状态、账户、组织或协作入口。

## 左侧导航区

目标是管理个人任务，不承载执行过程、文件树或协作信息。

| 模块 | 内容与规则 |
|---|---|
| 工作台标识 | 由应用标题栏统一显示，导航区不重复；不显示头像、账户、组织切换或在线状态。 |
| 新建任务 | 导航最上方的主操作；创建后自动聚焦输入框。 |
| 最近 | 显示默认工作目录中 Pi 已记录的会话，按最近活动时间倒序排列，不随当前所在项目变化；分组默认展开且可折叠。展开后默认显示最新 3 条，每次点击“显示更多”继续按既有时间顺序展示 5 条，直到全部显示。条目默认显示单行截断标题与最近活动时间，仅当前会话执行中时以“执行中”代替时间。当前会话为选中态，其余条目可直接切换以恢复历史对话。列表为空时显示简短说明，扫描期间显示低干扰的读取状态。默认工作目录不作为项目展示。历史列表来自本地 Pi 会话文件，与当前 RPC 连接无关：重建 RPC 连接期间保留已加载的列表与分页状态，只刷新内容，不清空导航。 |
| 项目 | 仅显示用户添加的本地项目。点击项目行展开或折叠：展开时按该项目目录查询 Pi 已记录的会话，默认显示最新 3 条，每次点击“显示更多”继续按既有时间顺序展示 5 条，同时保留当前任务；折叠时收起列表且不重复查询。分组加号添加项目，项目行加号（悬浮或聚焦时出现）在该项目中创建任务。 |
| 设置 | 固定在导航底部，只管理本地偏好、工具与安全策略。 |

任务列表项显示单行截断标题与最近活动时间；只有当前会话在 Agent 执行中时改为“执行中”。导航不展示未连接、正在连接、已连接或连接失败等 RPC 连接状态。选中态必须具有背景和文字变化。删除不作常驻操作。

会话列表只展示 Pi 已写入存储的会话；尚未产生任何消息的空会话不在列表中，直到其第一条消息被 Pi 落盘（此时活动项目下仍以“当前任务”行保留它的入口）。当前打开的会话必须始终在列表中可见并保持选中态：列表只加载最新几条时，若当前会话不在其中，仍需把它保留在列表里，不得退化为“当前任务”行，也不得以项目名或本地标题替代真实会话的标题。运行中的任务不可切换历史会话，切换入口需处于禁用状态并保留可见标签。切换其他项目的会话时，桌面端需先在该项目目录重建 Pi RPC，再加载目标会话；重建与加载期间导航保留全部历史记录、不显示连接过程提示，仅将切换入口置为不可点击。

顶部“新建任务”始终在默认工作目录中创建会话，并将会话加入“最近”。添加项目使用模态收集显示名称和源文件夹；源文件夹由原生目录选择器确定。项目导航不是文件树，不展示项目内文件。

## 顶栏

- 顶栏只在已有对话时显示；空白初始态不占用主区顶部空间。
- 顶栏横跨主工作区，高 52–60px，并以低对比度底部分隔线与执行流区分。
- 左侧显示项目或工作目录图标与可内联编辑的任务标题；标题过长时截断。顶栏不提供导出、断开或更多操作等入口。
- RPC 与 Agent 生命周期状态不进入顶栏或对话消息。连接过程在后台静默执行，不展示等待或状态提示；连接失败使用模态弹窗说明影响、原因和重试路径，等待输入使用原生交互对话框。
- 顶栏不放文件树、原始日志、复杂工具参数、账户入口或协作功能。

## 对话与执行流

它是任务唯一的工作叙事，按时间自上而下呈现用户意图、智能体行为与结果。

| 类型 | 呈现与默认状态 |
|---|---|
| 用户指令 | 清晰消息块靠右呈现，宽度随内容自适应且不超过内容列的大部分，带圆角，完整显示。 |
| Agent 回复 | 结构化自然语言；长内容可折叠。 |
| 执行计划 | 简短步骤清单，标记完成状态。 |
| 工具调用 | 名称、目的与进度；默认折叠为用户可理解的摘要。 |
| 工具输出 | 日志、命令输出、错误堆栈；默认折叠。 |
| 结果卡片 | 文件、链接、代码、表格或变更；视觉突出。 |

已完成过程不可被新消息替换或丢失。工具摘要应描述用户目标，例如“正在读取项目配置”，而不是仅暴露工具名。RPC 连接、Agent 运行、自动重试和上下文压缩属于独立状态层，不得生成对话节点；当前阶段不展示独立运行状态条。等待输入使用原生交互对话框；连接失败使用模态弹窗，其余操作错误使用主区错误面板。

### 响应组

一次用户指令与其后续 Agent 输出组成一个响应组；桌面端按 Pi 的事件事实把该组投影为“执行过程 + 主结果”，不新增对话节点。

| 内容 | 归类与默认状态 |
|---|---|
| 用户指令 | 响应组的起点，完整显示。 |
| 执行过程 | 思考、中间说明、工具调用、工具输出，以及带工具调用的助手消息（含其中的文本）；运行时默认展开，运行稳定结束后默认折叠。 |
| 主结果 | 组内最后一条正常完成的纯文本助手消息；不随执行过程折叠，且在运行结束后保持展开；与执行过程之间以细分隔线区隔。 |
| 候选结果 | 运行中最后一条纯文本助手消息；若随后发生工具调用或新的助手消息，则退回执行过程。 |
| 部分结果 | 终止原因为 `aborted`、`length` 或 `error` 时的文本内容；按“已停止 / 被截断 / 执行未完成”说明，不称为最终答案。 |

- 折叠触发器同时说明状态与点击后的行为，例如“执行中”“用时 50 秒 · 展开执行过程”“用时 50 秒 · 收起执行过程”“已停止 · 查看过程”“执行未完成 · 查看过程”。
- 不存在执行过程的简单回复不显示空的折叠控件。
- 展开或收起某次执行过程只影响该响应组；收起总过程不得销毁工具卡与思考块各自的展开状态。
- 历史会话与实时消息使用同一分类规则；历史缺少可靠运行耗时时隐藏耗时，不做估算。
- 定案只在 Pi 报告会话级运行稳定结束后发生；单次底层运行结束、自动重试尚未确定时不得提前把内容标为最终结果。

## 结果卡片

每张卡片包含类型图标、标题、简短描述、必要元信息和一个主操作。主操作可为打开、预览、复制、下载或应用变更；次级动作放入更多菜单。

- 每张卡片只允许一个视觉主操作。
- 代码与 Diff 默认只显示摘要和有限行数，完整内容在主区抽屉或模态中查看。
- 表格或结构化数据可内嵌预览，但需要限制高度。
- 下载、应用变更或覆盖文件时必须说明影响对象和后果。

## 输入区

输入区固定在主区底部，并与消息内容列对齐。它以圆角悬浮输入卡呈现，包含附件、多行输入框、模型选项及发送或停止操作。工作目录/分支上下文仅在尚未连接、需要建立会话时显示。

- 初始态可将工作目录、执行位置和分支等上下文显示在输入卡上方的附属条带；对话态仅在需要时保留，不能取代会话顶栏。
- 输入框最小高度约 44px，可向上扩展但应设最大高度；整张输入卡应保持柔和边框、12px 以上圆角和轻微悬浮层级。
- 附件与各种选项均为次级控制，不得挤压核心输入区域。
- 输入为空时发送按钮禁用；运行中，主操作切换为停止。
- 用户可在运行中保留草稿，但默认不并发提交当前任务；并发执行必须明确新建任务。
- 切换任务或意外关闭时应恢复未发送草稿。

## 设置页

| 分类 | 内容 |
|---|---|
| 外观 | 深浅色模式、字体大小、界面密度。 |
| Agent | 默认模型、默认思考强度、默认执行模式。 |
| 工具 | 本地工具开关、默认工作目录、终端与浏览器偏好。 |
| 数据 | 本地会话保存、导出记录、清理历史记录。 |
| 安全 | 危险操作确认、文件访问范围、外部连接授权策略。 |

设置页不得包含账户资料、订阅、账单、团队成员、角色权限、组织空间、通知偏好或快捷键配置。
