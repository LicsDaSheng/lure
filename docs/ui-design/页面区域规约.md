# 页面区域规约

## 应用标题栏

- 使用无系统装饰的 48px 自定义标题栏。
- 左侧提供关闭、最小化和最大化/还原。
- 中部显示当前工作目录，过长时从中间或开头截断，并保留可访问名称。
- 右侧可提供“选择目录”“重新启动”“停止 Pi”；运行状态必须同时使用文字与图标，不能只依赖颜色。
- 标题栏不提供模型、会话、工具、账户或协作入口，这些能力属于 Pi TUI。

## 终端工作区

- 终端工作区挂载 xterm.js，并在获得焦点后将键盘输入原样转发给 PTY。
- 终端输出不得被 React 重新排版、Markdown 化或转换为消息卡片。
- xterm.js 负责选择、scrollback、链接呈现、ANSI 色彩、alternate screen 和光标。
- 终端容器必须可聚焦；点击空白区域应恢复终端焦点。
- 字体使用可靠的等宽字体栈，默认字号 13px，行高约 1.25。

## 空状态和错误状态

- 未启动时显示当前工作目录、简短说明和“启动 Pi”。
- 启动中显示低干扰进度，不伪造 Pi 输出。
- 启动失败时说明发生了什么、影响和下一步，并提供“重试”“选择目录”。
- Pi 正常退出后保留已有终端内容，并显示可访问的退出状态与“重新启动”。
