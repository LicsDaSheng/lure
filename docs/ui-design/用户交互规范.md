# 用户交互规范

## 终端生命周期

| 操作     | 系统行为                                                                    |
| -------- | --------------------------------------------------------------------------- |
| 启动应用 | 读取默认工作目录，创建终端并启动 Pi。                                       |
| 选择目录 | 使用原生目录选择器；先停止当前 Pi，再在新目录启动。取消选择不影响当前会话。 |
| 输入     | xterm.js 的字节序列直接写入 PTY，不做命令解析。                             |
| 粘贴     | 由 xterm.js 和 Pi TUI 的 bracketed paste 协议处理。                         |
| resize   | FitAddon 计算列数/行数；只发送正数尺寸，并合并密集变化。                    |
| 停止     | 先请求终止 Pi；完成后保留屏幕内容并显示退出状态。                           |
| 重启     | 停止旧进程并在相同目录创建新的 PTY/Pi。                                     |
| 关闭窗口 | 回收 Pi 子进程、PTY reader 和相关任务。                                     |

## 错误与恢复

- 启动失败必须区分：Pi 未找到、目录无效、PTY 创建失败和子进程启动失败。
- 错误文案依次说明发生了什么、对终端的影响、可执行的恢复操作。
- 输出转发失败或 Pi 意外退出时，不清空已显示内容。
- 用户可随时通过重新启动恢复；不得自动无限重启。

## 键盘和焦点

- Pi TUI 拥有终端区域内的键盘语义，包括 `Ctrl+C`、`Escape`、快捷键和 slash commands。
- Lure 不抢占终端快捷键；窗口级操作使用可点击按钮。
- 启动成功后自动聚焦终端；模态目录选择结束后恢复终端焦点。
