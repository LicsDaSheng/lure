# 用户交互规范

## 任务生命周期

| 操作 | 系统行为 |
|---|---|
| 新建任务 | 创建空白会话，进入主区并聚焦输入框。 |
| 最近对话 | 默认工作目录中由 Pi 记录（已落盘）的会话进入“最近”，按最近活动时间倒序排列；“最近”不随当前所在项目变化，默认展开并支持折叠。 |
| 浏览更多会话 | “最近”与已展开项目的会话列表默认显示最新 3 条；仍有记录时显示“显示更多”，每次点击沿当前时间顺序追加 5 条。 |
| 恢复历史会话 | 在“最近”或已展开的项目中选择已记录的会话：Pi 加载对应会话文件并返回其状态，桌面端据此重建历史对话与工具结果；会话属于其他项目时先在该目录重建 Pi RPC；Pi 扩展取消或任务运行中时不改变当前对话。整个切换过程是一个事务：周期内不显示连接或加载提示，仅将切换入口置为不可点击；历史列表刷新不阻塞会话加载，在事务结束后后台完成。刷新后列表若只保留最新几条，目标会话仍须留在列表中并保持选中态，不能从列表里消失。 |
| 添加项目 | 在模态中选择本地源文件夹并填写项目名称；创建后进入该项目的空白会话。 |
| 展开项目 | 按该项目目录查询 Pi 已记录的历史会话并列出；再次点击折叠并收起列表。 |
| 查看会话标题全文 | 导航会话行标题列占行内固定剩余宽度、超长时常态截断；悬停该行（或键盘聚焦）且标题确实溢出时，在原位以跑马灯往复滚动展示完整标题，移开后回到截断态；不使用原生悬浮提示，系统开启“减弱动态效果”时不滚动。 |
| 连接 Pi | 启动与握手在后台静默执行，输入卡不提供手动连接入口，也不显示等待、进度或状态提示；失败时用模态弹窗说明影响与原因，并提供重新连接。 |
| 项目内新建任务 | 在所选项目目录启动或复用 Pi RPC，并创建空白会话；运行中的任务不可切换。 |
| 发送指令 | 记录真实用户消息，创建对应的助手轮次。 |
| Agent 执行 | 依序更新助手内容、工具摘要与阶段结果。 |
| 等待输入 | 通过原生交互对话框收集补充内容。 |
| 运行结束 | 恢复输入与发送能力，保留真实回复和工具结果。 |
| 删除任务 | 说明影响范围并要求最终确认；删除后回到空状态。 |

## Agent 状态与反馈

- RPC 连接生命周期、Agent 运行生命周期与对话消息必须分别建模；生命周期事件不得转换为用户、助手或系统对话消息。
- 连接过程静默执行：导航、顶栏、对话流与输入区都不展示连接中或已连接状态；只有连接失败需要用户处理时才弹窗提醒。
- 历史会话切换是独立于 `connection.phase` 的事务状态：连接重建到目标会话加载完成期间不接受新的切换请求，全程不显示连接过程提示。
- 对话流只记录真实的用户消息、助手消息，以及关联到助手轮次的工具执行。
- `agent_start`、`agent_end`、`agent_settled`、自动重试和上下文压缩只更新内部运行状态；当前阶段不展示独立的运行状态条。
- 运行中通过输入区停止操作、流式助手内容和工具进度提供反馈；收到 `agent_settled` 后仅恢复输入能力，不据此宣称任务成功完成。
- 等待输入通过原生交互对话框表达；用户停止与助手错误在对应助手轮次内说明。

## 输入区快捷操作

- `Ctrl+L` 打开模型选择框：provider 作为页签、当前 provider 的可用模型在下方单选展示；选择模型后必须点击“确认选择”才切换。
- 快捷操作不提供配置入口，模型切换结果仍以 Pi RPC 返回状态为准。

## 渐进展开

- 默认呈现关键结果和摘要；长日志、原始参数和完整堆栈按需展开。
- 当前正在运行的响应组默认展开执行过程；收到 `agent_settled` 后默认收起过程，但不折叠主结果。
- `agent_end` 仍可能后续自动重试、压缩重试或排队续跑，不得仅依据该事件提前固化最终结果。
- 已完成响应组的折叠触发器使用“展开执行过程”/“收起执行过程”等动作文案；有可靠计时时可附带“用时 N 秒”，历史数据无可靠计时时不猜测。
- 展开或收起某项工具调用不得影响其他内容。
- 完整内容使用抽屉或模态在当前任务内打开；关闭后恢复原滚动位置和展开状态。
- 折叠项应说明内容类型和规模，例如“查看 128 行命令输出”。

## 错误与恢复

错误信息必须依次说明：发生了什么、对任务的影响、用户下一步可采取的动作。

```text
无法读取目标文件
原因：文件不存在或当前工具没有访问权限。
影响：智能体无法继续生成基于该文件的修改。
操作：[重试] [更换文件] [查看详细日志]
```

- 不只展示错误码或堆栈。
- 连接失败（找不到 Pi、启动失败、握手超时、进程退出、通信中断）使用模态弹窗，说明影响与原因，并提供重新连接或稍后处理；其余操作错误在主区以错误面板内联说明，且与连接失败不重复提示。
- 可重试错误提供重试入口；需要选择时提供明确入口。
- 不自动重复高成本或具有外部影响的操作。

## 风险操作与确认

以下操作在执行前必须二次确认：删除本地文件、任务或历史记录；覆盖已有文件；批量应用变更；运行会修改系统或项目状态的命令；向外部服务发送内容或上传文件。

确认层必须说明操作内容、影响对象、是否可恢复，以及取消或返回路径。

## 空状态

首次使用或无任务时，主区不显示会话顶栏；展示简洁欢迎语和底部悬浮任务输入卡。欢迎语可引用当前工作目录或项目名称，位于主区视觉中心略偏下。个人工作流示例为可选内容，不应挤压留白或输入区域。不得展示团队邀请、账户配置、订阅或协作引导。
