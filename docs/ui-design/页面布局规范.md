# 页面布局规范

## 总体布局

采用左侧任务导航与单一主工作区的双栏布局，移除右侧上下文区。

```text
┌──────── 左侧标题区：窗口控制 · 折叠 ────────┬──────────── 主区标题栏：任务标题 · 拖动区（48px）────────────┐
├────────────── 左侧导航（272px）─────────────┼────────────────────── 主工作区 ──────────────────────┤
│ [ 对话 | 项目 ]                            │                                                              │
│ 对话：[新建对话] · 最近                    ├──────────────────────────────────────────────────────────────┤
│ 项目：用户添加的本地项目                   │ 对话与执行流                                                  │
│                                                                      │ 输入区：附件 · 多行输入框 · 工具/模型 · 发送/停止                │
│ [设置]                                                              │                                                                      │
└──────────────────────────────────────────────────────────────────────┴──────────────────────────────────────────────────────────────┘
```

## 尺寸与响应式

| 元素         | 桌面端                                                                    | 窄窗口                                 |
| ------------ | ------------------------------------------------------------------------- | -------------------------------------- |
| 应用标题栏   | 高 48px；按双栏分成左侧控制区和右侧任务标题区，不形成横跨两栏的第三层背景 | 保持窗口控制与左栏折叠入口可用         |
| 左侧导航     | 展开时固定 272px；背景 `#F6F6F8`，以 `#E8E8EB` 细线与主区分隔             | 可由标题栏按钮折叠，折叠后主区占满宽度 |
| 主工作区     | 填满余下空间；对话内容列最大宽度 720px 并居中                             | 占满视口宽度                           |
| 顶栏         | 仅已有对话时显示，高 56px，背景同主区，底部 `1px #EEEEF0` 分隔            | 标题截断                               |
| 对话与执行流 | 对话态位于顶栏和输入卡之间；滚动视口填满主工作区，内容列居中              | 保持独立滚动，避免整页滚动             |
| 输入区       | 固定于 720px 内容列底部，距窗口 20–24px，以悬浮输入卡呈现                 | 固定底部，次级选项可折叠               |
| 完整内容预览 | 主区抽屉或模态                                                            | 使用全屏抽屉或全屏预览                 |

## 空间与层级

- 使用 8px 间距基准：组件内为 8/12/16px，消息或卡片组间为 16–24px。
- 左栏使用 `#F6F6F8`，主区使用近白 `#FEFEFF`，以 `1px #E8E8EB` 分隔；不使用沉重阴影。
- 桌面窗口移除系统默认装饰并使用透明窗口背景，最外层应用框以 16px 圆角裁切并使用 `#E8E8EB` 细边框，使窗口四角真实透出桌面背景；内部使用高 48px 的自定义应用标题栏。标题栏按双栏边界分色：左侧控制区与导航统一使用 `#F6F6F8`，右侧标题区与主工作区统一使用 `#FEFEFF`，两者之间只保留与正文连续的竖向分隔线，不增加横跨窗口的独立色带。展开时左侧依次提供关闭、最小化、最大化/还原和左栏折叠；三个窗口按钮使用紧凑的 24px 水平节奏，折叠按钮紧随窗口控制组并保留清晰的视觉间隔。右侧显示任务标题并承担拖动。折叠后这些窗口级操作进入主区标题栏。标题栏不放账户、状态或任务操作。
- 左栏顶部使用“对话 / 项目”分段 Tab，默认选择“对话”；选中项必须同时使用背景和文字变化，不能只依靠颜色。从“项目”切回“对话”时回到默认工作目录并创建初始空白对话；从“对话”进入“项目”时恢复最近一次进入的用户项目及其对话，尚无项目访问记录时保持默认工作目录并创建初始空白对话。Tab 引发的会话切换期间，主工作区覆盖轻量页面加载动画，侧栏和窗口控制保持可见。重复点击已选中的 Tab 不重置当前内容。任务运行或会话切换期间不可执行会改变对话的 Tab 切换。
- “对话”Tab 下先显示高 44px 的“新建对话”导航行及细分隔线，再于 20–24px 后显示“最近”分组；不得显示项目分组。“最近”展示默认工作目录中 Pi 已记录的会话，按最近活动时间倒序排列，且不随当前所在项目变化，默认展开并可折叠。
- “项目”Tab 下仅显示用户显式添加的本地项目，不显示“新建对话”与“最近”。项目与对话行高 36–40px、圆角 8px，选中背景为 `#E9E9ED`。“最近”与已展开项目的会话列表默认显示最新 3 条，剩余记录通过“显示更多”按钮按每次 5 条渐进展示。项目行可展开或折叠：展开时显示该项目的历史会话与当前任务，并在悬浮或聚焦时显示项目内新建任务按钮。
- 初始态不显示主区顶栏：欢迎内容限制在 720px 内容列内并整体下移 60–80px；48px 图标容器后依次保持标题 24px、说明 20px、示例 32px 的垂直间距。
- 对话态顶栏横跨整个主区；标题栏内容使用主区内边距定位，不与居中的对话内容列强制对齐。
- 超宽屏时消息、执行摘要、结果卡片和输入卡共用居中的窄内容列，避免文本行宽无限扩张。
- 对话滚动视口不受内容列最大宽度约束，应填满整个主工作区，使垂直滚动条贴齐客户端右边缘。
- 对话滚动视口使用纵向 Flex 布局：内容列使用剩余高度，输入卡在视口底部保持可见。内容列不得在输入卡之外再强制 `min-height: 100%`，避免空状态产生一段等于输入卡高度的虚假滚动量。
- 桌面窗口根容器禁止滚动与 overscroll；仅对话视口允许纵向滚动，并在水平和垂直边界阻止滚动链传递，不得因触摸板回弹露出应用外层背景。
- 输入区始终保持可见，以 `#FFFFFF`、20px 圆角、`#E8E8EB` 描边和 `0 6px 24px rgba(0,0,0,.05)` 的轻阴影呈现。输入卡顶部固定显示高 36px 的只读会话上下文条，展示当前对话所在的工作目录与分支，不提供手动连接操作。
- 视觉优先级依次为：用户任务、Agent 结果、执行状态、工具日志。
- 不将辅助信息固定在右侧；只允许通过主区渐进展开。
