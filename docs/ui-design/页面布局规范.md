# 页面布局规范

## 总体布局

采用左侧任务导航与单一主工作区的双栏布局，移除右侧上下文区。

```text
┌──────────────────────── 左侧导航（240–280px）──────────────────────┬────────────────────────── 主工作区 ──────────────────────────┐
│ Lure ▾                                                              │ 对话态顶栏：任务标题 · 更多操作 · 本地视图/导出                  │
│ [新建任务]                                                          ├──────────────────────────────────────────────────────────────┤
│ ─────────────────────────────────────────────────────────────────  │ 对话与执行流                                                       │
│                                                                      │                                                                      │
│ 任务：今天                                                         ├──────────────────────────────────────────────────────────────┤
│                                                                      │ 输入区：附件 · 多行输入框 · 工具/模型 · 发送/停止                │
│ [设置]                                                              │                                                                      │
└──────────────────────────────────────────────────────────────────────┴──────────────────────────────────────────────────────────────┘
```

## 尺寸与响应式

| 元素 | 桌面端 | 窄窗口 |
|---|---|---|
| 左侧导航 | 固定 256px；背景 `#F6F6F8`，以 `#E8E8EB` 细线与主区分隔 | 转为左侧抽屉，默认收起 |
| 主工作区 | 填满余下空间；对话内容列最大宽度 720px 并居中 | 占满视口宽度 |
| 顶栏 | 仅已有对话时显示，高 56px，背景同主区，底部 `1px #EEEEF0` 分隔 | 标题截断，保留更多操作 |
| 对话与执行流 | 对话态位于顶栏和输入卡之间；滚动视口填满主工作区，内容列居中 | 保持独立滚动，避免整页滚动 |
| 输入区 | 固定于 720px 内容列底部，距窗口 20–24px，以悬浮输入卡呈现 | 固定底部，次级选项可折叠 |
| 完整内容预览 | 主区抽屉或模态 | 使用全屏抽屉或全屏预览 |

## 空间与层级

- 使用 8px 间距基准：组件内为 8/12/16px，消息或卡片组间为 16–24px。
- 左栏使用 `#F6F6F8`，主区使用近白 `#FEFEFF`，以 `1px #E8E8EB` 分隔；不使用沉重阴影。
- 左栏顶部为高 56px 的紧凑产品行，仅显示产品名与下拉指示；新建任务为高 44px 的无填充导航行，后接细分隔线。
- “今天”分组在分隔线下方 24px 显示，标题为 13px 次级文字；任务行高 38–40px、圆角 8px，选中背景为 `#E9E9ED`。
- 初始态不显示主区顶栏：欢迎内容限制在 720px 内容列内并整体下移 60–80px；48px 图标容器后依次保持标题 24px、说明 20px、示例 32px 的垂直间距。
- 对话态顶栏横跨整个主区；标题栏内容使用主区内边距定位，不与居中的对话内容列强制对齐。
- 超宽屏时消息、执行摘要、结果卡片和输入卡共用居中的窄内容列，避免文本行宽无限扩张。
- 对话滚动视口不受内容列最大宽度约束，应填满整个主工作区，使垂直滚动条贴齐客户端右边缘。
- 对话滚动视口使用纵向 Flex 布局：内容列使用剩余高度，输入卡在视口底部保持可见。内容列不得在输入卡之外再强制 `min-height: 100%`，避免空状态产生一段等于输入卡高度的虚假滚动量。
- 桌面窗口根容器禁止滚动与 overscroll；仅对话视口允许纵向滚动，并在水平和垂直边界阻止滚动链传递，不得因触摸板回弹露出应用外层背景。
- 输入区始终保持可见，以 `#FFFFFF`、20px 圆角、`#E8E8EB` 描边和 `0 6px 24px rgba(0,0,0,.05)` 的轻阴影呈现。未连接时显示高 36px 的工作目录条带；已连接的对话态移除该条带，由主区顶栏承载目录与任务上下文。
- 视觉优先级依次为：用户任务、Agent 结果、执行状态、工具日志。
- 不将辅助信息固定在右侧；只允许通过主区渐进展开。
