# 页面布局规范

## 总体布局

```text
┌──────────── 自定义标题栏（48px）────────────┐
│ 窗口控制 · Lure / 工作目录 · 终端操作       │
├─────────────────────────────────────────────┤
│                                             │
│              Pi TUI / xterm.js              │
│                                             │
└─────────────────────────────────────────────┘
```

- 应用采用单一主工作区，不设置常驻左栏或右栏。
- 自定义标题栏高 48px；左侧是 macOS 窗口控制，中部显示工作目录，右侧放置选择目录、重启和停止。
- 终端填满标题栏之外的全部空间；内边距仅用于避免文字贴边，不限制为对话内容窄列。
- 最小窗口为 720 × 480；窗口变化后 FitAddon 重新计算列数和行数并同步 PTY。
- 根容器禁止页面滚动和 overscroll，滚动只发生在 xterm.js viewport。
- 启动或失败面板覆盖终端区域，但不遮挡窗口控制。
