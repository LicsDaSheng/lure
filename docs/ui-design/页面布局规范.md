# 页面布局规范

## 总体布局

采用左侧任务导航与单一主工作区的双栏布局，移除右侧上下文区。

```text
┌──────────────────────── 左侧导航（240–280px）──────────────────────┬────────────────────────── 主工作区 ──────────────────────────┐
│ 品牌 / 个人工作台                                                   │ 对话态顶栏：任务标题 · 更多操作 · 本地视图/导出                  │
│                                                                      ├──────────────────────────────────────────────────────────────┤
│ [+ 新建任务]                                                        │ 对话与执行流                                                       │
│                                                                      │                                                                      │
│ 任务：今天                                                         ├──────────────────────────────────────────────────────────────┤
│                                                                      │ 输入区：附件 · 多行输入框 · 工具/模型 · 发送/停止                │
│ [设置]                                                              │                                                                      │
└──────────────────────────────────────────────────────────────────────┴──────────────────────────────────────────────────────────────┘
```

## 尺寸与响应式

| 元素 | 桌面端 | 窄窗口 |
|---|---|---|
| 左侧导航 | 固定 240–280px，可折叠至 64px | 转为左侧抽屉，默认收起 |
| 主工作区 | 填满余下空间；对话内容列最大宽度 880–960px 并居中 | 占满视口宽度 |
| 顶栏 | 仅已有对话时显示，高 52–60px，固定在主区顶部 | 标题截断，保留更多操作 |
| 对话与执行流 | 对话态位于顶栏和输入卡之间，独立滚动 | 保持独立滚动，避免整页滚动 |
| 输入区 | 固定于主区底部，以悬浮输入卡呈现 | 固定底部，次级选项可折叠 |
| 完整内容预览 | 主区抽屉或模态 | 使用全屏抽屉或全屏预览 |

## 空间与层级

- 使用 8px 间距基准：组件内为 8/12/16px，消息或卡片组间为 16–24px。
- 左栏和主区以低对比度细分隔线区分；不使用沉重阴影。
- 初始态不显示主区顶栏：欢迎语位于主区视觉中心略偏下，底部保留输入卡。
- 对话态顶栏横跨整个主区；标题栏内容使用主区内边距定位，不与居中的对话内容列强制对齐。
- 超宽屏时消息、执行摘要、结果卡片和输入卡共用居中的窄内容列，避免文本行宽无限扩张。
- 输入区始终保持可见，以白色或近白色的圆角悬浮卡呈现；可使用极轻边框或阴影，不使用贯穿主区的重分割线。
- 视觉优先级依次为：用户任务、Agent 结果、执行状态、工具日志。
- 不将辅助信息固定在右侧；只允许通过主区渐进展开。
