# Pi 桌面终端设计规约

本规约定义 Lure 以 Rust PTY + xterm.js 呈现 Pi 原生 TUI 后的界面和交互基线。

## 产品定位

- 面向单个用户的 Pi 桌面终端，不包含账户、组织、团队、订阅或协作能力。
- 主工作区直接呈现 Pi 原生 TUI；模型、会话、命令、工具和扩展交互均由 Pi TUI 提供。
- Lure 只提供窗口、工作目录、PTY 生命周期和错误恢复，不在终端外重复实现 Pi 功能。

## 实现约束

- 终端是唯一主工作区，不新增常驻侧栏、右栏、文件树或独立对话流。
- 不解析 ANSI 来推断 Agent、工具或会话语义。
- Pi 未启动、启动失败或已退出时，必须提供清晰的工作目录与恢复操作。
- 若实现偏离本规约，应先更新规约再修改界面。
