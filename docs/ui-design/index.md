# 个人智能体工具工作台设计规约

本规约定义 Lure 个人智能体工具工作台的界面和交互基线。它适用于所有前端页面、组件和状态设计；具体实现必须遵循本目录的文档。

## 产品定位

- 面向单个用户的个人智能体工作台，不包含账户、组织、团队、成员、角色、订阅、账单、共享空间、通知偏好或快捷键配置。
- 工作台通过对话驱动任务，集中呈现智能体的计划、执行、工具活动和结果。
- 采用“左侧任务导航 + 单一主工作区”的双栏布局；不设置常驻右侧上下文区。
- 文件、代码、Diff、日志与结构化结果通过主工作区中的结果卡片、内嵌预览、抽屉或模态呈现。

## 设计优先级

1. 用户任务与最终结果。
2. 当前智能体状态和需要用户介入的信息。
3. 可追溯但可折叠的执行过程。
4. 按需展开的工具细节与原始日志。

## 实现约束

- 不得新增常驻右栏、文件树、账户入口、团队协作入口或快捷键设置。
- 不得只依靠颜色传达状态、错误或选中状态。
- 不可逆或具有外部影响的操作，必须遵循《用户交互规范》的确认规则。
- 若实现与本规约存在冲突，应先更新规约，再修改界面。
